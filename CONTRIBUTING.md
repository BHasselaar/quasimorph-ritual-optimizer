# Contributing

Contributions are welcome.

1. Fork the repository and create a focused branch.
2. Install the project and development tools:

   ```powershell
   python -m pip install -e . -r requirements-dev.txt
   ```

3. Add or update tests for behavior changes.
4. Run `pytest` before opening a pull request.
5. Explain any changes to ritual formulas and include a reproducible source or in-game validation method.

Please keep mechanics assumptions isolated and clearly documented. Do not present unverified formulas as confirmed game code.
