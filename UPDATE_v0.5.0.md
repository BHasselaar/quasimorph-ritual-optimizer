# Update to v0.5.0

Replace the changed files from the update archive, or replace the project with the full archive.

- Search inventory by component name.
- Duplicate names are blocked case-insensitively.
- Click inventory/result headings to sort.
- Balanced is the default objective; only Jackpot, Balanced, Sidegrade, and Minimum Disenchant remain.

- Exact brute force is substantially faster through precomputed pairwise contributions and compact multi-process scoring.

Your inventory and settings in `%APPDATA%\QuasimorphRitualOptimizer` remain user data and are not part of the source update.
